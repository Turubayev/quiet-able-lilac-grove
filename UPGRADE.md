# Доработка и доказательства готовности

Дата: 2026-10-09.

## Реализовано

Локальное веб-рабочее место сотрудника на FastAPI. По умолчанию точные выдержки из shop.json с источниками и отказом при нехватке фактов. Опциональный Claude API с явным согласием, ключами только на сервере, проверкой ссылок и усечённых ответов. Host/Origin, локальный token и предел тела запроса. Перед копированием требуется сверка; любое изменение отменяет подтверждение. Автоматической отправки нет.

## Аналог и применённый подход

[Chatwoot](https://github.com/chatwoot/chatwoot)

Черновик для оператора, видимые источники и подтверждение перед копированием. Каналы Chatwoot, CRM и автоматизация рассылок не интегрированы.

## Запуск и проверка

```bash
pip install -r requirements.txt
python -m pytest -q
python -m uvicorn service:app --host 127.0.0.1 --port 8780
# Открыть http://127.0.0.1:8780
```

Регрессионные тесты: `python -m pytest -q`. Локальная среда проверки: Windows, Python 3.12. CI проверяет отдельную чистую среду.

## Что требуется для оценки 10/10

Оплатить/настроить provider только при необходимости. В этой доработке оплачиваемый API не вызывался; тесты используют mock. Нужен набор обезличенных RU/KZ обращений с эталонами, оценка ложных обещаний, языка и экономии времени. Проверка source_ids не гарантирует достоверность каждой фразы; вывод проверяет сотрудник. Для публичного многопользовательского сервиса нужны аутентификация и отдельная модель хранения.

Инженерные тесты подтверждают поведение кода; они не измеряют клиническую, гидрологическую или коммерческую точность. Метрики на синтетике нельзя переносить на реальные данные. Оценка 10/10 сейчас не заявляется.
