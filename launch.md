# Материалы запуска

## Текст будущего сайта

**Ответик — черновики ответов покупателям за несколько шагов.**

Для небольших магазинов, которые ежедневно отвечают на вопросы о доставке, оплате и возвратах.

Добавьте правила магазина, вставьте вопрос покупателя и получите короткий черновик на русском или казахском. Проверьте ответ и отправьте его привычным способом.

Мы создаём помощника на базе Claude API. Сейчас доступен ранний локальный прототип; веб-версия запланирована. Ищем магазины для первого пилота.

Для участия в пилоте напишите на корпоративную почту, которую основатель добавит перед публикацией страницы.

Перед публикацией: добавьте реальный контакт, сведения об основателе, дату запуска и описание обработки данных. Не публикуйте этот текст как готовый работающий веб-сервис.

## Описание для заявки на английском

Otvetik is an early-stage, bootstrapped project building an AI reply assistant for small online shops. We have a local prototype that combines a shop's delivery, payment and return policies with a customer question to request a draft reply through the Claude API in Russian or Kazakh. A shop employee reviews each draft before sending it. We plan to use Claude API credits to test answer quality and develop a simple web interface. We are currently preparing our first pilot and do not yet have paying customers.

Используйте описание только если оно соответствует фактам на дату подачи. Bootstrapped означает, что проект развивается без внешних инвестиций. В анкету отдельно внесите реальные страну, статус бизнеса, дату основания, сайт и корпоративную почту. Не указывайте регистрацию компании, клиентов или работающую интеграцию, если их нет.
