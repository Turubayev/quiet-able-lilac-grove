# Ответик

Минимальный прототип помощника для небольших магазинов: вопрос покупателя + правила магазина → черновик ответа через Claude API на русском или казахском. Сотрудник проверяет и отправляет ответ самостоятельно.

Это ранний локальный прототип. Сайт пока не опубликован, клиентов и выручки не заявляем. Название рабочее: доступность домена и прав на него не проверена.

## Проверить без ключа

Нужен Python 3.10 или новее. В папке проекта выполните:

```powershell
python app.py "Сколько стоит доставка в Алматы?" --preview
```

Предпросмотр показывает подготовленный запрос, а не сгенерированный ответ. Он ничего не отправляет в Anthropic.

## Получить настоящий ответ

Замените примеры в shop.json реальными правилами своего магазина. В Claude Console создайте API-ключ и выберите доступную модель. Ключ храните только локально в переменной окружения, не в сайте и не в репозитории.

```powershell
$env:ANTHROPIC_API_KEY = Read-Host "Введите API-ключ" -MaskInput
$env:ANTHROPIC_MODEL = Read-Host "Введите идентификатор доступной модели из Console"
python app.py "Сколько стоит доставка в Алматы?"
python app.py "Төлемді қалай жасауға болады?" --language казахский
```

Пример ввода ключа рассчитан на PowerShell 7. Не присылайте ключ в чат. API-запросы расходуют баланс или кредиты. Текст вопроса и правила магазина передаются Anthropic; не вставляйте персональные данные покупателей. Прототип не сохраняет переписку и не отправляет ответы покупателям.

## Самый короткий путь к запуску

1. Найдите один магазин, готовый попробовать помощника. Соберите 10 обычных вопросов и правила магазина.
2. Проверьте ответы на этих вопросах, включая случаи, где информации нет. Проверьте казахский с носителем языка.
3. Купите подходящий домен и заведите почту на том же домене. Укажите реальные сведения об основателе и проекте.
4. Опубликуйте простую страницу с описанием продукта, его текущей стадией и рабочей почтой. Готовый текст — в launch.md.
5. Подайте заявку в Claude Console, описав текущую стадию честно. Покупка домена и создание прототипа сами по себе не гарантируют одобрения и не означают регистрацию компании.

Для первых пользователей можно оказывать услугу вручную: магазин присылает обезличенные вопросы, вы возвращаете проверенные черновики. После проверки спроса — веб-форма и платная подписка. Цену определите после пилота.
